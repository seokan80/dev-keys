## 삭제와 수정

포트의 여분 0과 호스트 이름의 오타를 고친다. **x는 글자 하나, dd는 줄 전체**다. `r` 뒤에 글자 하나를 누르면 현재 글자를 바꾸며 입력 모드로 들어가지 않는다.

입력 중 Backspace는 커서 앞 글자를 지운다. 줄 첫 칸에서 Backspace를 누르면 이전 줄과 합친다. 이 연습은 자동 들여쓰기를 끄고 `backspace=indent,eol,start`인 기본 자료를 기준으로 한다.

`u`는 변경 하나를 되돌리고 Ctrl+R은 다시 실행한다. 한 번 입력 모드에 들어갔다가 Esc로 나온 내용은 한 변경으로 묶인다. 일반 모드에서 연속으로 누른 x는 각각 별개의 변경이다. 본문뿐 아니라 실제 Vim의 undo/redo가 놓는 커서 위치도 함께 확인한다.

`ggI`로 첫 줄 앞에서 입력을 시작하고 Enter로 줄을 나눈다. Esc 뒤에 커서가 새 줄의 첫 글자에 놓이는 이유를 확인한다. 모든 단계는 새 파일이 아니라 현재까지 편집한 본문에서 이어진다.

Ctrl+R은 **편집기에 포커스가 있을 때만** redo로 처리한다. 밖에서는 브라우저의 단축키가 유지된다. 한글 조합 입력 대신 영문·기호를 사용한다.
