## 검색·저장·종료

`/단어`와 Enter로 현재 커서 다음의 일치를 찾는다. 끝에 도달하면 처음으로 순환한다. `n`은 같은 방향, `N`은 반대 방향으로 찾는다.

이번 입문 편집기는 영문·숫자·공백·밑줄·하이픈으로 된 기본 검색을 지원한다. 정규식 기호를 글자 검색으로 잘못 흉내 내지 않고 미지원 안내를 표시한다. 실제 Vim의 정규식·대소문자 옵션은 이후에 다룬다.

| 명령          | 동작                                  |
| ------------- | ------------------------------------- |
| `:w` + Enter  | 연습 파일의 저장본 갱신               |
| `:q` + Enter  | 변경이 저장돼 있을 때 닫기            |
| `:q!` + Enter | 저장하지 않은 변경을 남기지 않고 닫기 |
| `:wq` + Enter | 저장하고 닫기                         |

수정한 뒤 `:q`를 누르면 E37 안내가 나온다. 닫기 전에 저장이 필요하다는 뜻이다. `:w` 단계에서는 저장본까지 채점하며, 마지막 `:wq` 단계에서는 저장본과 닫힌 상태도 확인한다.

여기서 저장은 **브라우저 연습 세션의 가상 파일 저장본**이다. 내 컴퓨터의 파일을 쓰거나 탭을 닫는 명령이 아니다. 연습 완료 기록만 브라우저에 남고 편집한 본문은 저장소로 전송하지 않는다.
